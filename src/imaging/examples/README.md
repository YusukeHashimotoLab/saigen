# Example run

One complete example run, `zif8_vial_5s/`, kept here so that `make_panel.py`
can be tried without a camera. It is the source of the photograph in the
paper's Figure 6(b) and of the panel layout in Figure 6(c, d).

| | |
|---|---|
| Sample | ZIF-8 (a metal-organic framework) suspension — white sediment under a clear supernatant — synthesised by the platform on 2026-07-02 |
| Vessel / mixing | screw-top vial, **not** stirred during synthesis |
| Dispensing | the second precursor solution ("solution 2") dispensed over **5 s** |
| Photographed | 2026-07-14 13:25 (`captured_at` `20260714_132511`), twelve days after synthesis, once the suspension had settled |
| Camera | Logitech C920n, gain 0, focus 180, white balance manual 4600 K; **exposure was still at the older, brighter setting used before this module's reference exposure of 20** (see caveats) |
| Light | NEEWER RGB62 — white 5600 K for geometry, then HSI red/green/blue at 1 % intensity |
| Geometry (auto-detected, not locked) | `meniscus_y` 359, `sediment_front_y` 474, `liquid_bottom_y` 620, body columns 632–744, fill fraction 0.708 |

Contents (one run directory as written by `acquire.py`):

- `ref_white.jpg` — white-light reference photo (used for geometry detection)
- `shot_red.jpg`, `shot_green.jpg`, `shot_blue.jpg` — monochromatic captures
  at nominal 625 / 525 / 465 nm
- `profiles.csv` — per-row optical density (OD) for each wavelength
- `spectral.png` — OD-vs-depth figure generated by `acquire.py`
- `summary.json` — capture metadata (geometry, LED intensity, warnings, etc.)

The `"warning"` strings in `summary.json` were translated to English from the
original Japanese capture logs; no other field was modified.

Render the panel with:

```
python3 make_panel.py examples/zif8_vial_5s --out /tmp/panels
```

(the run directory is resolved relative to the current directory first and
then to `src/imaging/`, so the same command also works from the repository
root as `python3 src/imaging/make_panel.py examples/zif8_vial_5s`.)

## Data caveats

This run is published as a **worked example of the imaging pipeline**, not as
a validated measurement. Specifically:

- **The white reference is clipped.** 43 % of the liquid rows are saturated
  in the metering channel of `ref_white.jpg` (the whole clear supernatant
  region). `make_panel.py` therefore draws no white transmittance curve by
  default and shows the white photograph for visual reference only;
  `--with-white` plots it anyway, as a plain solid line (clipped rows are
  not marked in the plot; their fractions are in the stdout table and the
  draft caption). Every run
  in this measurement batch has a white reference clipped between 62 % and
  90 % over the vial-neck region, which is why this batch should be re-measured
  with a lower white intensity.
- **The 465 nm channel is clipped too.** Its secondary (G) channel saturates
  over 39 % of the liquid rows, again in the clear supernatant. Where the
  465 nm curve sits at T ≈ 1 it is reporting a clipped sensor reading, not a
  measured transmittance. The 625 nm and 525 nm curves are unclipped over
  the full depth range.
- **Old exposure setting.** This batch was photographed before the camera
  exposure was lowered to the reference value of 20 recorded in
  [`../config/camera_reference.json`](../config/camera_reference.json).
  Absolute brightness — and therefore absolute transmittance — is not
  comparable with runs captured after that change; the depth-resolved shape
  within this single run is what the example demonstrates.
- **Wavelengths are nominal.** 625 / 525 / 465 nm are the LED's rated
  values, not independently measured (±10–15 nm).
- **Geometry is auto-detected, not locked.** `geometry_locked` is `false`, so
  the meniscus/body/liquid-bottom rows come from per-run detection on the
  white reference rather than from a locked frame.

For the same reasons this single run is **not** offered as a comparison of
dispensing times: a dispensing-time series would have to be captured under
one fixed exposure and one locked frame, which this batch was not.
